# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

Is a scripting language that enables you to create dynamically updating content, control multimedia, animate images, and pretty much everything else.

## 3. What three problems does Git & GitHub solve?

Git helps store changes to files and their history.
GitHub is a platform for collaborating, reviewing code, and maintaining projects online.
## 4. What happens when you `fork` a repository?

It creates a separate version of the original project so that you can freely make changes to it without changing the original project.

## 5. What happens when you clone a repository?

You download the repository from GitHub to your local computer.

## 6. What is a Pull Request?

With a Pull Request, you ask the project owner to review the changes you made to your version (branch or fork) and merge them into the original version.
